# 🚴 SpeedBike

Android-додаток для велосипедистів: відстежує **швидкість**, **дистанцію** та
**маршрут на карті**, і **дзвенить**, коли ти проїхав задану кількість кілометрів.

<p align="center">
  <em>Kotlin · Jetpack Compose · OpenStreetMap (osmdroid) · Fused Location · Foreground Service</em>
</p>

## ✨ Можливості

- **Швидкість у реальному часі** — великий спідометр (км/год) із GPS.
- **Дистанція та час** — лічильник кілометражу і тривалість поїздки.
- **Середня та максимальна швидкість**.
- **Сигнал на дистанції** — встановлюєш ціль (наприклад, 10 км), і коли проїдеш —
  телефон **дзвенить і вібрує**, поки не вимкнеш сигнал.
- **Карта з маршрутом** — лінія показує, де саме ти їхав (як у картах). Карта
  безкоштовна (OpenStreetMap), **API-ключ не потрібен**.
- **Трекінг у фоні** — запис триває навіть із вимкненим екраном (foreground-сервіс).
- **Темний дизайн**, зручний для вулиці.

## 📲 Як отримати готовий APK (без Android Studio)

Кожен пуш до репозиторію автоматично збирає APK через GitHub Actions:

1. Відкрий вкладку **Actions** у репозиторії на GitHub.
2. Вибери останній успішний запуск **Build APK**.
3. Внизу, у розділі **Artifacts**, завантаж `speedbike-debug-apk`.
4. Розпакуй і встанови `app-debug.apk` на телефон
   (увімкни «Встановлення з невідомих джерел»).

## 🛠️ Збірка локально

Потрібні **JDK 17** та **Android SDK** (наприклад, через Android Studio).

```bash
./gradlew assembleDebug
# готовий APK: app/build/outputs/apk/debug/app-debug.apk
```

Або просто відкрий папку проєкту в **Android Studio** (Ladybug 2024.2.1+) і натисни ▶️.

## 🔐 Дозволи

| Дозвіл | Навіщо |
|--------|--------|
| Геолокація (точна) | Вимірювання швидкості та запис маршруту |
| Сповіщення | Постійне сповіщення активної поїздки |
| Фоновий сервіс (location) | Трекінг при вимкненому екрані |
| Вібрація | Сигнал при досягненні цілі |

Додаток нічого не надсилає в інтернет, окрім завантаження плиток карти OpenStreetMap.

## 🧱 Архітектура

```
MainActivity (Compose)
      │  спостерігає
      ▼
RideRepository (StateFlow<RideState>)  ◄──── оновлює ──── TrackingService (foreground)
      ▲                                                          │
      │ команди (Intent: START/PAUSE/STOP/…)                     ├── FusedLocationProvider (GPS)
RideViewModel ───────────────────────────────────────────────────┤
                                                                  └── AlarmController (звук + вібрація)
```

- **`TrackingService`** — єдиний «писар» стану: рахує дистанцію (з фільтрацією
  GPS-шуму), швидкість, час, формує маршрут і вмикає сигнал при досягненні цілі.
- **`RideRepository`** — спільне джерело правди (`StateFlow`) на весь процес.
- **`RouteMap`** — osmdroid `MapView`, вбудований у Compose через `AndroidView`.
