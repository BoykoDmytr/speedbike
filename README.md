# 🚴 SpeedBike

Android-додаток для велосипедистів: відстежує **швидкість**, **дистанцію**,
**набір висоти** і **маршрут на карті**, **дзвенить** на заданій дистанції,
веде **історію поїздок** з графіками, рахує **рекорди й цілі**, а ще має
живого **піксельного вело-пета** (тамагочі), який росте з твоїх реальних поїздок.

<p align="center">
  <em>Kotlin 2.0 · Jetpack Compose · Material 3 · Room · WorkManager · OpenStreetMap (osmdroid) · Fused Location · Foreground Service</em>
</p>

## ✨ Повний функціонал

### 🏁 Трекінг поїздки
- **Спідометр у реальному часі** — великий круговий індикатор швидкості (км/год або mi/h).
- **Дистанція, час, середня та максимальна швидкість.**
- **Набір висоти** і **калорії** — рахуються наживо (калорії за формулою MET з урахуванням ваги).
- **Запис у фоні** — трекінг триває з вимкненим екраном (foreground-сервіс + сповіщення).
- **Авто-пауза** — час не йде, поки стоїш на місці.
- **Фільтрація GPS-шуму** — відкидаються неточні точки, дрібні «тремтіння» не накручують дистанцію.
- **Тримати екран увімкненим** — за бажанням екран не гасне під час їзди.

### 🔔 Сигнал на дистанції
- Телефон **дзвенить і вібрує**, щойно ти проїхав задану ціль.
- **Інтервальний режим** — сигнал кожні N км (наприклад, нагадування пити воду).
- Керування прямо зі **сповіщення** (вимкнути сигнал / зупинити поїздку).
- **Голосові підказки (TTS)** — озвучення дистанції та середньої швидкості щокілометра.

### 🗺️ Карта та маршрут
- **Лінія маршруту** малюється наживо — видно, де саме ти їхав.
- **4 шари карти** без жодного API-ключа: звичайна (Mapnik), **велосипедна (CyclOSM)**,
  **супутник (Esri)**, **рельєф (OpenTopoMap)**.
- **🌙 Нічна карта** — інверсія кольорів тайлів для темної карти ввечері.
- **Слідування за велосипедистом** + кнопка повторного центрування; готовий маршрут
  автоматично вписується в екран.

### 📚 Історія та аналітика поїздки
- Кожна поїздка **зберігається локально** (Room); маршрут кодується компактно.
- **Список історії** → перегляд поїздки: карта + всі показники.
- **Графіки**: швидкість і висота відносно пройденої дистанції.
- **Спліти по кілометрах** — час і середня швидкість кожного км стовпчиками.
- **Видалення** поїздок.
- **Експорт у GPX** — відкривай у Strava / Komoot / Google Earth.
- **🖼️ Картинка-підсумок** — генерується зображення 1080×1350 з маршрутом і
  статистикою, щоб ділитися в Instagram / Telegram.

### 📊 Статистика, рекорди, цілі
- **Особисті рекорди**: усього км, кількість поїздок, найдовша поїздка,
  найшвидші 5 км, макс. швидкість, найбільший підйом, сумарний набір висоти, калорії.
- **Цілі**: тижнева (за замовч. 50 км) і місячна (200 км) — редагуються, зі смужками прогресу.
- **Виклик тижня**: 100 км за тиждень.
- **🔥 Теплокарта** — усі твої маршрути накладені на одну карту.

### 🐹 Велопет (тамагочі)
Піксельний звір-велосипедист, чий стан залежить від твоєї **реальної** їзди.

- **Петля «км → пет»**: кожен км дає **енергію**, **монети** та **XP**; набір висоти
  додає **силу**, висока швидкість — спортивну **форму**.
- **Рівні** за кривою XP та **еволюція**: 🥚 яйце → малюк → підліток → дорослий → 👑 чемпіон
  (за сумарними км: 1 / 25 / 100 / 500).
- **Стиль** залежить від того, як ти їздиш: 🏔️ гороходець, ⚡ спринтер,
  🏃 марафонець або універсал.
- **Настрій** (сонний / голодний / сумний / задоволений / щасливий / в захваті) —
  він же показується емодзі у віджеті.
- **Денна ціль + серія днів 🔥** — катаєшся щодня, серія росте; пропустив — обнуляється
  (рятує «❄️ заморозка серії»). Без поїздок пет «іржавіє» й сумує, але **ніколи не вмирає** —
  відновлюється кількома поїздками.
- **3 щоденні квести** (на дистанцію / швидкість / набір висоти) з нагородою в монетах.
- **12 досягнень** (перша поїздка, 50/100/500 км, сенчурі, 40 км/год, серія 7/30 днів, чемпіон…).
- **🛒 Магазин і кастомізація**: шапки (кепка/шолом/корона), окуляри, майки, велосипеди,
  їжа (відновлює енергію) та заморозка серії — пет одягається в куплене.
- **🌍 Віртуальна подорож Європою** — реальні км ведуть пета маршрутом
  Київ → Львів → Краків → Прага → … → Київ (петля ~7100 км, з лічильником кіл).
- **Нагадування** — «Спайк зголоднів 🐹», коли давно не катався (через WorkManager).

### ⚙️ Налаштування
Кілометри/милі · голосові підказки · тримати екран · авто-пауза · **нічна карта** · вага (для калорій).

### 🧩 Віджет на головний екран
Темний віджет показує **дистанцію за сьогодні**, **суму за тиждень** і **настрій пета**.
Тап відкриває застосунок; оновлюється автоматично після кожної збереженої поїздки.

## 📲 Встановлення на телефон

Найпростіше — за прямим посиланням (репозиторій публічний, вхід не потрібен):

**➡️ https://github.com/BoykoDmytr/speedbike/releases/latest**

Завантаж `SpeedBike.apk`, відкрий на телефоні, дозволь встановлення з невідомих
джерел → «Встановити». На першому запуску надай доступ до геолокації.

> Кожен пуш у репозиторій автоматично пересоберає APK і оновлює це посилання.

## 🔄 Оновлення

Зміни код → коміт → пуш → **GitHub Actions** збирає APK і оновлює реліз `app-latest`.
Перевстанови APK за тим самим посиланням — оновлення стає **поверх** попереднього
(застосунок має стабільний підпис), історія, пет і налаштування зберігаються.

## 🛠️ Збірка локально

Потрібні **JDK 17** та **Android SDK** (Android Studio Ladybug 2024.2.1+).

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## 🧱 Архітектура

```
MainActivity (Compose + Navigation)
  ├── HomeScreen ─────────► RideViewModel ──► TrackingService (foreground)
  │     спідометр, карта,                       ├── FusedLocationProvider (GPS, швидкість, висота)
  │     сигнал, керування                       ├── AlarmController (звук + вібрація)
  │                                             ├── VoiceAnnouncer (TTS)
  │                                             └── зберігає поїздку ─► Room + оновлює віджет + годує пета
  ├── History / RideDetail ─► HistoryViewModel ─► Room (історія, графіки, спліти, GPX, картинка)
  ├── Stats / Heatmap ──────► StatsViewModel ───► рекорди, цілі, виклики, теплокарта
  ├── Pet / Shop ───────────► PetViewModel ─────► PetEngine + PetStore (стан пета у JSON)
  └── Settings

спільний стан поїздки:  RideRepository  (StateFlow<RideState>)
спільний стан пета:     PetRepository   (StateFlow<PetState>)
нагадування:            PetReminderWorker (WorkManager)
віджет:                 SpeedBikeWidget  (AppWidgetProvider)
```

- **`TrackingService`** — єдиний «писар» стану поїздки: дистанція, швидкість, висота,
  калорії, сигнал, авто-пауза та збереження поїздки.
- **`PetEngine`** — чиста логіка гри-тамагочі (нагороди, спад, серія, еволюція, квести,
  досягнення); стан персистується як JSON у `PetStore`.
- **`RideRepository` / `PetRepository`** — спільні джерела правди (`StateFlow`) на весь процес.
- **Room** — локальна база історії поїздок.
