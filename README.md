# 🚴 SpeedBike

Android-додаток для велосипедистів: відстежує **швидкість**, **дистанцію**,
**набір висоти** та **маршрут на карті**, **дзвенить** на заданій дистанції,
зберігає **історію поїздок** і експортує маршрути у **GPX**.

<p align="center">
  <em>Kotlin · Jetpack Compose · Room · OpenStreetMap (osmdroid) · Fused Location · Foreground Service</em>
</p>

## ✨ Можливості

- **Швидкість у реальному часі** — великий спідометр (км/год або mi/h).
- **Дистанція, час, середня та максимальна швидкість.**
- **Набір висоти та калорії** — рахуються під час поїздки.
- **Сигнал на дистанції** — телефон **дзвенить і вібрує** на заданій цілі.
  Можна увімкнути **інтервальний режим** — сигнал кожні N км.
- **Карта з маршрутом** — лінія показує, де ти їхав. Шари: звичайна,
  **велосипедна (CyclOSM)**, **супутник**, **рельєф**. Без API-ключа.
- **Історія поїздок** — кожна поїздка зберігається; список + перегляд маршруту
  на карті, видалення, **експорт у GPX** (Strava / Komoot / Google Earth).
- **Голосові підказки** — озвучення дистанції кожен кілометр.
- **Налаштування** — км/милі, голос, тримати екран увімкненим, авто-пауза, вага.
- **Трекінг у фоні** — запис триває навіть із вимкненим екраном.
- **🐹 Велопет (тамагочі)** — віртуальний звір, що живе з твоїх поїздок (див. нижче).

## 🐹 Велопет (тамагочі)

Маленький звір-велосипедист, чий стан залежить від твоєї реальної їзди.

- **Петля «км → пет»** — кожен км дає енергію в «батарейку», монети та XP; набір
  висоти додає силу, швидкість — спортивну форму.
- **Денна ціль + серія днів 🔥** — катаєшся щодня, серія росте; пропустив —
  обнуляється (рятує «заморозка серії»). Не катаєшся — пет сумує й «іржавіє»
  (відновлюється кількома поїздками; ніколи не «вмирає»).
- **Еволюція**: яйце → малюк → підліток → дорослий → чемпіон, а **стиль**
  (марафонець / спринтер / гороходець / універсал) залежить від того, як ти їздиш.
- **Щоденні квести**, **досягнення**, **магазин** (шапки, окуляри, майки,
  велосипеди, їжа) та кастомізація пета.
- **🌍 Віртуальна подорож** — реальні км рухають пета мапою Європи (Київ → Львів
  → Краків → …).
- **Нагадування** — «Спайк зголоднів 🐹», коли пора прокотитися.

## 📲 Встановлення на телефон

Найпростіше — за прямим посиланням (репозиторій публічний, вхід не потрібен):

**➡️ https://github.com/BoykoDmytr/speedbike/releases/latest**

Завантаж `SpeedBike.apk`, відкрий на телефоні, дозволь встановлення з невідомих
джерел → «Встановити». На першому запуску надай доступ до геолокації.

> Кожен пуш автоматично пересоберає APK і оновлює це посилання.

## 🔄 Оновлення

Зміни код → коміт → пуш → GitHub Actions збирає APK і оновлює реліз `app-latest`.
Перевстанови APK за тим самим посиланням — оновлення стає поверх попереднього
(додаток має стабільний підпис), історія та налаштування зберігаються.

## 🛠️ Збірка локально

Потрібні **JDK 17** та **Android SDK** (Android Studio Ladybug 2024.2.1+).

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## 🧱 Архітектура

```
MainActivity (Compose + Navigation)
  ├── HomeScreen ── RideViewModel ──► TrackingService (foreground)
  │                                      ├── FusedLocationProvider (GPS, швидкість, висота)
  │                                      ├── AlarmController (звук + вібрація)
  │                                      └── VoiceAnnouncer (TTS)
  ├── HistoryScreen / RideDetailScreen ── HistoryViewModel ──► Room (історія поїздок)
  └── SettingsScreen
            спільний стан: RideRepository (StateFlow<RideState>)
```

- **`TrackingService`** — єдиний «писар» стану: дистанція (з фільтрацією
  GPS-шуму), швидкість, висота, калорії, сигнал, збереження поїздки.
- **`RideRepository`** — спільне джерело правди (`StateFlow`) на весь процес.
- **Room** — локальна база історії поїздок (маршрут зберігається закодованим).
