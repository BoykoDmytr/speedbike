# Тека для артів пета 🐹🦊🐱

Сюди кладуться вихідні зображення тварин (стрічки з 3 формами).

**Поклади 3 файли (саме такі назви):**

- `fox.png` — лис (3 форми в один ряд: малюк → підліток → дорослий)
- `cat.png` — кіт (3 форми)
- `hamster.png` — хом'як (3 форми)

Вимоги: прозорий фон (PNG з альфою), тварини у ряд із проміжками між ними.

Далі асистент сам розріже кожну стрічку на 3 форми, покладе їх у
`app/src/main/res/`, прив'яже аксесуари та анімує (велик + погойдування).
